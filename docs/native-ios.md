# 原生 iOS 客户端

codex-link iOS 使用 SwiftUI 原生界面，通过证书固定的 HTTPS 客户端调用 Mac 网关。iOS 不加载 WKWebView；Mac 浏览器界面仍保留，两者共用设备配对、读取发现和桌面 Codex IPC。

## Codex Remote 参考

参考目标为 `ChatGPT.app` 1.2026.300 的 `ChatGPT.framework`。用 `ida-domain` 对 framework 的 arm64 Mach-O 静态字符串引用进行定点分析，定位到以下 Codex Remote 组件和界面路径：

- `CodexHomeTaskList`、`CodexHomeStartContent`、`CodexHomeDraftContent`：任务首页及新建任务输入区。
- `CodexRemoteTaskRowContent` 与 `CodexRemoteTaskRowTrailingStateIndicatorsPart`：任务行和状态提示。
- `CodexRemoteThreadListFilterMenuContent`、`CodexRemoteHostFilterButton`、`CodexRemoteHostFilterRow`：列表组织及主机筛选。
- `CodexRemoteProjectSortOrder`、`CodexTaskListProjectPagination`：项目排序和分页。
- `CodexRemoteStatusSheet`、`CodexRemoteThreadView`、`CodexRemoteComposerState`：任务状态、对话和输入流程。
- 字符串引用定位到最近排序、项目任务加载更多、重命名、审批卡片和后续消息行为等 UI 路径。

源二进制是闭源 framework；本项目没有复制其实现或资源。定点 xref 和反编译代码片段保存在本次工作区 `build/remote-analysis/`，可用其中 `workdir.txt` 找到 IDA 临时工作目录。新的完整证据导出位于相邻 `Payload/ChatGPT.app/codex-remote-analysis/full/`；本轮源码映射、Serena 用法和新增行为见 [复刻工程进展](reverse-reconstruction.md)。上述组件证据支持交互结构参考，不用于声称像素级复刻；视觉细节根据 iOS 系统控件和可访问性尺寸重新实现。

## 原生实现

- 首页按最近任务／项目浏览；任务列表服务端分页，每页最多 100 项，提供更多加载和项目钻取。
- 会话页用原生消息、单行工具入口、待审批请求、运行状态、停止操作和 composer。
- 首页任务行、侧栏会话行和聊天顶栏均提供「···」操作：重命名、置顶、标为未读、项目归属、从最新完成轮次分支、复制深层链接／Markdown／工作目录、归档和永久删除；按本机／远程、只读能力显示。打开未读会话自动标为已读，不重新载入消息流。分支成功后切到新会话，Markdown 复制会按顺序分页读完可用内容和截断详情，内容变化或历史不完整时明确报错。永久删除的精确范围、二次确认和恢复备份见 [会话操作说明](workspace-actions.md#永久删除的精确范围)。
- composer 加号菜单提供照片图库、拍照和文件导入；图片会转换为 JPEG 后作为会话附件上传，沿用 20 MiB 限制。模拟器没有相机时拍照入口不可用。
- 消息列表只在用户主动向更早消息滚动时预取：首条可见消息进入已加载消息的前 8 条即请求上一页，空轮询、初始布局及向下浏览不触发。快速响应静默插入，响应应用前记录首条可见消息 ID 与屏幕 Y，关闭插入动画并补偿精确位移，短暂追踪懒布局的后续测量；继续拖动和惯性滚动保留用户位移。抵达顶部仍待响应时，使用微型进度环保底；下拉采用平方根阻尼（100pt 手指位移约 40pt 内容位移），54pt 临界点轻触反馈与微放大，松手以阻尼 0.8 的弹簧悬停于 36pt，完成后折叠收起。会话页采用双层返回：前层随手指移动，底层以 30% 视差展开，黑色遮罩从 35% 线性减到 0；拖动达到页面宽度 38% 或右甩速度达到 800 pt/s（已移动超过 2%）时返回，否则柔和回弹。左上角返回按钮也使用同一完成动画。
- 自动滚动只响应实际可见消息变化；上翻历史时暂停跟随，空轮询不改变阅读位置。点击“回到最新消息”或主动发送后恢复跟随。
- 回复中的 Markdown 链接以蓝色下划线显示。本机文件引用支持中文、空格、编码路径及行号后缀，点击后通过当前会话的已授权文件 ID 下载：图片和文本先在应用内预览，其他类型直接交给系统文件打开面板；文件过期或不在可下载列表时显示错误。预览左上角为「完成」，右上角「···」提供系统文件打开；图片可缩放并保存到相册，文本保留语法高亮，Markdown 默认渲染。文本超过 2 MiB 时明确提示预览上限，系统打开仍使用完整原文件。
- 「对话文件」采用一个居中的共享列，按最长文件名确定宽度，其余文件名与它左侧对齐；超长文件名受页面宽度约束并换行。已授权的消息图片附件也进入相同预览流程。
- 消息中的执行命令只显示一行命令摘要，不显示输出和行号。`/bin/zsh -lc "…"`、`bash -c '…'` 等带引号的 Shell 包装在摘要中仅显示内部命令；普通命令原样显示，详情与复制保留完整原始命令。点击任意命令均使用同一个详情页组件，上方显示完整命令、下方显示输出，自动依次读取剩余分段；加载失败可重试。详情随当前工具记录更新，命令与输出均无行号；保留语法着色、执行状态、失败退出码和耗时。MCP 与动态工具也使用同一入口查看输入／输出。
- 设置 → 任务与阅读提供“命令与输出自动换行”。详情页菜单可同步切换，关闭后长行横向滚动；偏好保存在当前设备，单行摘要始终保持一行。终端 ANSI SGR 前景色与粗体保留，OSC 和光标控制码被移除。
- 消息中的文件变更入口右侧和详情页顶部以绿色／红色显示完整补丁的新增／删除行数；后台按需读完分段后统计，避免将截断预览计为完整结果。
- 文件变更点击后打开独立差异页，顶部显示各文件共有的目录前缀，各文件分区仅显示剩余路径，并展示增删统计、差异片段、原／新行号、代码语法着色和增删底色，可折叠单个文件；不直接展示整段 raw patch。支持 unified diff、桌面端的路径加补丁投影及 apply_patch 文件标记，大于 2,000 行仍保持差异渲染。工作区与回复中的 diff／patch 代码块复用相同渲染器；“文件变更自动换行”独立控制差异长行。
- 文件预览使用本地 Runestone／Tree-sitter 编辑器，支持 Swift、Rust、Python、Bash、JS／TS、JSON、YAML、TOML、C、HTML、CSS 与 Markdown 语法高亮、行号、折叠、搜索和换行。完整 UTF-8 文件可编辑；最大 128 KiB，按 Mac 原子保存，基于读取修订值拒绝覆盖冲突。文件 BOM、权限位和换行符按原样保留。Markdown 可切换源码／渲染视图。
- 消息页右上角「···」使用原生 `Menu` 的默认宽度和系统背景，菜单项顺序、标签与对话操作菜单保持一致，包含工作区、模型与推理、消息发送设置、对话操作与新建对话；输入区下方不再保留模型与发送方式按钮。在“模型与推理”中，推理强度使用下拉菜单，优先采用所选模型目录提供的选项；切换模型保留兼容强度，否则采用模型默认值。目录没有强度信息时保留旧版通用选项作为回退。
- 输入框为空时以浅色提示当前已用上下文／上下文窗口及百分比，例如 `24K / 128K（18.8%）`；上下文与会话 Token 统一使用十进制 K／M。取日志最新有效 `last_token_usage.total_tokens` 与 `model_context_window`，与 CLI `/status` 使用相同字段，不使用会话累计费用用量。这里显示原始已用／窗口比例；CLI 剩余比例另有 12K 基线扣除，并非相同算法。`/status` 是 CLI 本地命令，未向模型发送它，也未新增 App Server 调用。打开会话后读取，每 15 秒更新；缺失日志、缺少有效窗口或远程不支持时显示“上下文用量暂无数据”。上下文投影需要新版 Mac 网关。
- 轻点发送按钮按草稿的默认发送方式提交；长按 450ms 打开底部“本次发送方式”菜单，可选择发送新消息、完成后发送或补充当前任务，选择后只对本次提交生效。长按松手不额外触发轻点发送。默认方式和普通／计划工作模式在「···」→ 消息发送设置中修改。
- 消息正文使用只读原生文本视图，支持系统长按选词、拖动选区手柄与复制；不提供编辑、粘贴等修改操作。整条回复的复制、分享与分支仍使用消息下方按钮。
- 消息、命令摘要及提交提示不加投影、模糊材质或外围晕影。消息滚动区域延伸到屏幕底部； composer 透明悬浮在消息之上，并根据自身高度为最后一条消息保留可滚动空间，背景仅作用于输入控件本身。
- 会话详情显示上下文、输入、缓存输入、输出与推理 Token，以及可展开的模型／服务档位费用明细。参考 [cc-sessions-viewer](https://github.com/jerrywu001/cc-sessions-viewer) 的累计快照差分、重复快照去重、恢复重置后继续累加与 `turn_context` 模型识别方式独立实现，未复制源码。缓存输入从总输入拆分计价，推理已含在输出中，不再重复收费。价格使用 `mac/data/model-pricing.json` 的公开短上下文 API 快照（2026-11-09，29 个模型），记录来源与日期；仅精确模型 ID 或其日期后缀匹配，未知型号／档位不套用其他价格。有无法计价部分时不显示误导性总额。此金额不是订阅账户账单，未计工具、长上下文或地区附加费用；缓存写入缺少保留时长时不估价。远程会话没有本地日志用量投影时明确提示。
- `python3 scripts/update-pricing.py` 通过指定的 [Jina 价格页](https://r.jina.ai/https://developers.openai.com/api/docs/pricing?latest-pricing-expanded=true) 更新快照，解析校验通过后原子替换；失败保留旧文件，正常运行统计不依赖网络。新版网关按文件时间／大小重新载入价格，单独更新价格无需重启；首次部署统计代码仍需重启 Mac 网关并安装新版 IPA。
- 消息页「···」→ 工作区提供工作区浏览、带面包屑的文件名搜索、右上角独立的文件选项菜单、排序、隐藏项显示、文件导入、文本预览、已暂存／未暂存差异，以及路径与评论回填，见 [工作区使用说明](workspace-browser.md)。新建项目的目录选择采用相同搜索和路径导航交互。
- 菜单采用 SwiftUI 原生 `Menu`；按钮、sheet、项目目录选择器、文件导入、分享、设置使用原生控件。
- iOS 的 JSON API 是版本化读取投影 `/api/native/v1`；已有的会话、设置和项目接口继续执行写操作，不代理任意 RPC。
- 文件编辑和导入仅开放于已认证并通过 CSRF 校验的本机可控会话；以工作区相对路径和文件修订散列限制编辑，只接受单链接 UTF-8 普通文件，编辑上限 128 KiB。导入上限 20 MiB、拒绝覆盖现有文件，不提供任意文件访问或命令执行。需更新并重启 Mac 网关，同时覆盖安装新版 IPA。
- URLSession 使用配对期间固定的 TLS 证书；Cookie 仅驻留内存。局域网 IPv4／外出 IPv6 仍由现有发现和地址选择逻辑管理。

## 保留边界

- CLI 来源会话先以只读历史显示；本机 `codex-tui` 会话在后台验证并转换成功后刷新为可交互会话，仍使用桌面端原有执行 owner。显式日志视图及不支持转换的来源保持只读。
- 命令、文件和权限审批及用户输入可在手机处理；computer-use、部分 MCP／结构化请求与计划批准仍由 Mac 处理。
- 未发送草稿按配对身份、主机和会话保存在本机；恢复时不自动发送，附件需重新选择。文字消息未确认时保留 payload 与请求 ID，供核对后重试。详见 [复刻工程与行为证据](reverse-reconstruction.md)。
- Markdown 覆盖常用标题、列表、行内格式、链接、代码区块和 GFM 表格。表格支持表头、列对齐、行底色、单元格内格式与链接、横向滚动，以及转义管道符和行内代码中的管道符。数学公式仍不在当前排版范围。
- 创建任务、浏览完整项目目录、覆盖 IPA 安装和账号切换之外的账户管理仍受现有 Mac 网关能力约束。

## 验证

Runestone 与 TreeSitterLanguages 按固定版本源码随工程集成：Runestone 与所选语法包许可及来源 SHA-256 见 `ios/Packages/Runestone/`。随包提供 15 种所选语法，不在构建时联网解析依赖。

运行 `bash scripts/test-ios-smoke.sh` 做隔离 IPv4／IPv6 网络、Keychain 与原生 API 冒烟。运行 `LINK_UI_TEST=1 bash scripts/test-ios-smoke.sh` 额外验证工具、代码、文件编辑／保存、历史滚动和工作区流程。fixture 使用临时 HOME、TLS 服务与合成会话，不读取实际 `~/.codex`。

命令详情与换行设置可单独运行 `LINK_UI_TEST=1 LINK_UI_TEST_CASE=NativeUITests/NativeFlows/testToolDetailsAndWrapping bash scripts/test-ios-smoke.sh`；不指定 `LINK_UI_TEST_CASE` 时执行完整 UI 流程。

IPA 构建使用 `bash scripts/build-ios.sh`。脚本按 `Info.plist` 版本生成未签名与 TrollStore 包，验证归档和 ad-hoc 签名，并写出 `build/SHA256SUMS.txt`。原生 UI 必须覆盖安装新 IPA；Bundle ID、Keychain service/account 和配对凭据标识不变，不需重新配对。

相机／图库入口、费用呈现及浏览器控件需要覆盖安装新版 IPA；工作区排序、隐藏项、文件导入和 token 用量 API 还需更新并重启 Mac 网关。

会话操作菜单更新也需要重启 Mac 网关并覆盖安装新版 IPA；置顶、未读和项目归属是 codex-link 偏好，不会同步改写桌面 App 的列表状态。

静默历史预取、消息表格、对话文件预览和工作区右上角菜单均为原生 iOS 改动，覆盖安装 IPA 后生效；保存图片仅在主动选择时请求添加照片权限。
