# 对话发现与历史读取

## 已实现

针对此前“只能看到一小部分项目和会话”的问题，新增第一方读取层，不修改内置上游快照。

| 功能 | 当前行为 |
| --- | --- |
| 本机发现 | 读取 `CODEX_HOME/state_*.sqlite` 的 `threads`，不再仅展示桌面来源；递归扫描 `sessions/`、`archived_sessions/` 的 JSONL 元信息补全缺失记录 |
| 默认范围 | 全部来源、未归档、非内部会话；可切换仅桌面、归档及内部会话 |
| 项目列表 | 从筛选后的完整集合生成项目索引及数量，不再依赖已加载的前 100 条；点击项目再分页加载会话 |
| 历史正文 | 从对应 JSONL 按页读取，支持更早记录、长消息分段展开、刷新及追加内容轮询 |
| 异常提示 | 日志缺失、ID 不一致、路径不安全、损坏记录、未写完的末行和超大记录均有提示 |
| 控制边界 | 非桌面来源／仅日志发现的会话只读，不自动恢复，不允许发送、审批、停止、上传或修改 |

本机“全部来源”不等于保证展示所有 Codex 版本、所有账户或所有机器的全部记录。无法恢复已经删除的日志正文。

## 数据从哪里来

```text
CODEX_HOME（默认 ~/.codex）
  ├── state_*.sqlite / threads         主要元信息、来源、归档状态
  ├── sessions/**/*.jsonl              日志首行发现 + 正文按需读取
  ├── archived_sessions/**/*.jsonl     同上
  ├── session_index.jsonl              数据库标题缺失时的标题补充
  └── .codex-global-state.json          桌面项目配置与显式归属
```

- 数据库选择**仍沿用上游按文件修改时间选择**，没有改成按 `state_<N>` 数字最大值选择，也不合并多个数据库。
- 数据库通过上游只读、支持 WAL 的连接读取；不迁移、不修复、不写入原库。日志和配置亦只读。
- JSONL 扫描只解析首行 `session_meta`，按会话 UUID 去重，不在发现阶段解析全部正文。缓存不会保留 `base_instructions` 等大块内容。
- 数据库记录优先；路径失效或 ID 不符时，可回退到同 ID 的有效日志。数据库不可用时退化为日志发现，并将这些记录全部视为只读。
- 数据库中的归档标记优先于日志所在目录；仅日志记录按目录判断。归档开关表示切换到归档集合，不是把归档与未归档混排。
- 标题优先数据库 `name` / `title`，缺失时使用标题索引中该 ID 最后一个有效标题；再缺失则显示“未命名会话”。

### 项目归属

优先保留有效的桌面显式项目分配及精确匹配的项目根目录；其他记录按完整 `cwd` 分组。不同工作树、子目录可以成为不同组，避免一个已保存的家目录或 Downloads 根目录吞并许多独立项目。

项目卡片中的历史目录分组不一定是已登记项目。后续 [项目管理改造](workspace-actions.md) 已允许将历史目录添加为项目，并显示空项目；`/api/projects` 现在合并桌面配置与 codex-link 自己的持久项目登记，新建仍复用原执行逻辑。

## 阅读与控制分开

- 原桌面白名单：数据库来源为 `Codex Desktop`、`codex_work_desktop`、`codex_mobile_bridge`，或 `originator` 为空且 `source=vscode`；内部会话另外排除。
- 符合该范围的桌面会话仍走原 IPC、owner、审批和发送逻辑；“符合范围”不是保证当前有可用 owner。
- CLI 会话初次显示只读历史；iOS 打开本机 `codex-tui` 会话后，会验证数据库记录和日志 ID 并尝试转换为桌面可控制来源，成功后自动刷新并继续使用原 IPC、owner、审批和发送逻辑。转换失败时保持只读并显示错误。
- exec、未知来源、远程 CLI 和仅日志记录继续只读；不允许通过转换接口更改这些来源。
- CLI 转换只更新匹配会话的 Codex 状态数据库 `originator`，不改写 JSONL 消息历史；要求会话未归档且不是内部／子代理会话。
- 支持 `originator=codex-tui` 且 `source=cli` 或 `vscode` 的组合；通过共享 App Server 创建的 TUI 会话也可能记录为 `vscode`，不会因此被排除。
- 桌面会话的详情里新增 **“只读查看完整日志”**，可在不额外激活会话的情况下检查日志；返回列表后正常打开，恢复原桌面交互视图。
- 前端隐藏输入与写操作，并拦截上游打开会话时的自动 reconnect；后端对非桌面会话的写接口独立返回 `403 read_only`。不是仅靠隐藏按钮保护。
- 历史中的工具调用和输出只作文本展示，不执行命令。思考摘要不进入历史索引或展示，不解析加密思考内容，不任意读取本地附件文件。图片暂显示附件占位说明。

局域网发现、IPv4／IPv6、首次配对、设备凭据、证书绑定及 CSRF 方案均不变。

## 接口与实现位置

所有数据接口继续要求原设备登录与同源检查，写接口保留 CSRF。

| 接口 | 用途 |
| --- | --- |
| `GET /api/sessions` | `q`、`offset`、`limit`（最多 100）、`archived`、`scope=all/desktop`、`internal`、`project`、`refresh`；返回 `sessions/total/hasMore/projects/warnings/unavailableHosts` |
| `GET /api/session-meta/<uuid>?host=local` | 获取新鲜的只读／桌面能力与日志可读标记 |
| `GET /api/history/<uuid>/timeline` | 本机只读正文分页；`limit`、`before` 游标 |
| `GET /api/history/<uuid>/changes` | 按 `epoch/after` 获取追加内容；替换、编辑或游标过期时重置 |
| `GET /api/history/<uuid>/detail` | 按消息 `key/version/offset` 分段读取长内容 |

旧 `/api/sessions/<uuid>/...` 路径仍兼容：桌面会话交给上游；非桌面会话的读取请求适配到只读层，写请求拒绝。

- `mac/history_catalog.py`：发现、能力判定、完整项目索引。
- `mac/history_reader.py`：JSONL 偏移索引、正文分页、版本／游标。
- `mac/history_http.py`：认证后路由及只读边界。
- `web/link-history.js` / `.css`：来源选择、项目卡片与只读聊天；与纯展示层 `link-ui.js` 分离。

## 性能与格式限制

- 发现缓存约 2 秒；刷新按钮可强制重新扫描元信息。
- 正文索引只常驻偏移、长度、角色与版本等信息，最多缓存 8 个文件。**首次打开或文件变化仍需扫描整个文件**，目前不是增量索引；特别大的活跃日志可能需要等待。
- 正文页最多 100 项，正文行 JSON 约 192 KiB；默认每页 20 项。普通预览 8000 字符、工具活动 180 字符，展开内容每段最多 16000 字符。
- 单条日志超过 8 MiB 会跳过并告警；发现阶段首行元信息上限为 1 MiB。
- 支持常见 `response_item` 消息／工具记录、公开摘要及 `event_msg` 消息回退，去除常见 event／response 镜像重复。未知格式不能保证完整还原。
- 损坏中间行跳过并提示，未完成末行下次重试；并发替换／截断会提示重读，而不是无限等待。
- `historyReadable` 表示找到了可验证归属的日志，**不保证其所有正文记录都完整或兼容**。
- 搜索为标题、cwd 和项目名匹配，尚无全文检索。
- SSH 主机仍沿用上游桌面范围；新增的全来源发现和 JSONL 只读视图仅针对当前 Mac。

## 更新与验收

1. 保留 `.local/` 与现有配对，正常停止旧 Mac 网关，再从本项目重新启动。
2. 保存手机未发送草稿，在 iOS 连接设置里刷新聊天页面。**本次读取功能不需要重装 IPA。**
3. 最近页选择“全部来源”，检查总数；项目页应展示完整分组，点击较早项目仍能找到会话。
4. 打开标有“只读”的历史：应显示正文和刷新按钮，不应出现可用输入框或恢复任务。
5. 长历史向前加载，长消息展开；缺失日志应有明确错误，不应伪装成完整空对话。

本次没有自动重启现有网关、安装手机、提交或推送代码。

## 验证范围

测试均使用临时数据库、合成日志、假 Codex 和回环监听；真实数据排查仅限上述元信息统计。

```sh
python3 -m unittest discover -s tests -v
python3 scripts/test-standalone.py
node scripts/test-web-ui.cjs
UI_BROWSER=webkit node scripts/test-web-ui.cjs
./scripts/test-ios-smoke.sh
```

- 读取改造时后端及资源回归 52 项：覆盖多来源／归档、完整项目索引、WAL 只读、路径边界、ID 匹配、分页、长 Unicode 内容、重复事件、工具文本、损坏／超大／截断日志、追加／替换游标、认证与只读写操作拒绝。后续项目管理回归见 [操作说明](workspace-actions.md#测试与尚未验证的范围)。
- 空 HOME、无上游兄弟目录的独立副本验证源码自包含。
- Chromium／WebKit 模拟 UI：项目索引、分页、只读无激活／写入、桌面显式日志视图，以及原有发送失败重试、草稿、停止、审批等回归。开发依赖安装见 [移动端 UI 说明](mobile-ui.md#验证)。
- 一次性 iOS 模拟器通过 Keychain、证书绑定与错误证书拒绝、IPv4／IPv6 回环下 WKWebView 认证及新读取控件加载。它不验证真实公网 IPv6，也不验证真实对话正文。

模拟 UI 和 fake bridge 通过不代表真实 Codex 版本的发送、审批或停止已验证；仍需在独立测试会话及自己的 iPhone 上验收。
